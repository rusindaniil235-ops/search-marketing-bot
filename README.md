# Помощник аналитика маркетинга Поиска

Учебный чат-бот для производственной практики. Он распознаёт тему вопроса по
ключевым словам и возвращает заранее подготовленный ответ по базовым понятиям
аналитики маркетинга Поиска.

Проект не подключается к внутренним системам Яндекса, не требует токенов и не
содержит корпоративных данных.

## Возможности

- 11 тематических интентов и безопасный fallback;
- объяснимый результат: тема, уверенность и совпавшие ключевые слова;
- локальный веб-интерфейс;
- консольный режим;
- автоматические unit-тесты и измерение точности/скорости.

## Требования

- Python 3.10 или новее;
- внешние библиотеки не требуются.

## Запуск веб-интерфейса

```bash
python3 server.py
```

Откройте `http://127.0.0.1:8000`.

## Консольный режим

```bash
python3 cli.py
```

## Проверки

```bash
python3 -m unittest discover -s tests -v
python3 evaluate.py
```

После оценки создаются:

- `artifacts/evaluation.json` — полный машинно-читаемый результат;
- `artifacts/evaluation.md` — краткий отчёт для человека.

## Архитектура

1. `normalize_text()` приводит запрос к единому регистру, заменяет `ё` на `е`
   и удаляет пунктуацию.
2. Для каждого интента считаются баллы за полные фразы и взвешенные ключевые
   слова; `*` в словаре означает совпадение по префиксу.
3. Побеждает тема с максимальным баллом. Если балл ниже порога, возвращается
   fallback с перечнем поддерживаемых тем.
4. Сервер на стандартной библиотеке принимает JSON через `POST /api/chat` и
   отдаёт структурированный ответ.

## Ограничения

- словарь нужно вручную расширять при появлении новых формулировок;
- бот не хранит контекст нескольких реплик;
- показатель уверенности — диагностическая эвристика, а не статистически
  калиброванная вероятность;
- тестовый набор учебный и не является репрезентативной выборкой всех запросов.
